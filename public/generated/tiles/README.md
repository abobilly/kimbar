# Procedural Placeholder Tiles

This directory contains **deterministic procedural placeholder tiles** for the Kimbar game.

## Overview

All 230 tiles defined in `specs/ai_jobs/tileset_manifest.json` have been generated as 32×32 PNG placeholders. These placeholders:

- ✅ **Eliminate all "missing tile(s)" warnings** during validation
- ✅ **Are deterministic** - same tile ID always generates the same image
- ✅ **Are easily identifiable** - subtle orange border and procedural pattern
- ✅ **Are transparent** - won't obscure gameplay during development
- ✅ **Are replaceable** - simply overwrite with real art

## Generation

Placeholders are generated using:

```bash
npm run gen:tiles:placeholders
```

This runs `scripts/generate-placeholder-tiles.mjs` which:
1. Reads the tileset manifest
2. Generates a unique procedural pattern for each tile ID (using the ID as a seed)
3. Creates a 32×32 PNG with:
   - Semi-transparent gray base (alpha: 30)
   - Deterministic pattern (checkerboard, diagonal, grid, or dots)
   - Orange border (1px) to clearly identify as placeholder

## Determinism

Each tile is generated deterministically from its ID:
- **Same ID → Same hash** (e.g., `tile.floor.marble.white_base` always produces `ec937a6bd8c4bf983c67bff9a0d4efcc`)
- Uses a seeded PRNG (mulberry32 variant) with hash of tile ID
- Pattern type, spacing, and other parameters derived from seed

## Replacing Placeholders

To replace a placeholder with real art:

1. **Create the real tile** (32×32 PNG, following the tileset manifest specification)
2. **Name it exactly** as specified: `{tile-id}.png` (e.g., `tile.floor.marble.white_base.png`)
3. **Overwrite** the placeholder file in this directory
4. **Verify** - run `npm run validate` to confirm no missing tiles

The orange border makes it easy to spot placeholders in-game during development.

## File Format

- **Size**: 32×32 pixels
- **Format**: PNG with RGBA (8-bit per channel)
- **Compression**: Level 9 (maximum)
- **File size**: ~150-200 bytes per tile

## Integration

Placeholders are validated by `scripts/validate.js`:
- Scans `public/generated/tiles/` for `*.png` files
- Checks against `specs/ai_jobs/room_tile_requirements.json`
- Reports: "230 defined, 230 generated (100%)"
- Confirms: "All 18 rooms have required tiles"
